## [ANEForge: Python Package Directly Programs Apple Neural Engine](https://arxiv.org/abs/2606.17090) ⭐️ 9.0/10

ANEForge is a new Python package that directly programs the Apple Neural Engine (ANE) for both inference and training, bypassing Apple's CoreML framework entirely. This breakthrough enables developers to have full control over the ANE, unlocking its full potential for machine learning workloads on Apple devices, which was previously limited by CoreML's abstraction. ANEForge compiles a lazy tensor graph into a single ANE program using 58 fused operators and 19 native bridge operators, achieving a call completion time of about 90 microseconds, near the engine's 70-microsecond dispatch floor.

rss · ArXiv ML (cs.AI) · Jun 17, 04:00

**Background**: The Apple Neural Engine is a dedicated AI accelerator found in Apple Silicon chips, used for on-device machine learning tasks. Previously, developers could only access the ANE through Apple's CoreML framework, which treated it as a scheduling option and often silently fell back to CPU or GPU. ANEForge bypasses CoreML by dispatching programs through the same ANE daemon and kernel-driver stack used internally by Apple.

## [LoopWM: 100x Parameter Efficiency via Looped World Models](https://arxiv.org/abs/2606.18208) ⭐️ 9.0/10

Researchers introduced Looped World Models (LoopWM), the first looped architecture for world modeling, which uses a parameter-shared transformer block to iteratively refine latent states, achieving up to 100x parameter efficiency over conventional approaches. This breakthrough establishes iterative latent depth as a new scaling axis for world simulation, orthogonal to scaling model size or data, potentially enabling more efficient and adaptive long-horizon simulation in AI systems like autonomous agents and robotics. LoopWM achieves adaptive computation by automatically scaling depth to match the complexity of each prediction step, and the paper reports up to 100x parameter efficiency compared to conventional world models.

rss · ArXiv ML (cs.AI) · Jun 17, 04:00

**Background**: World models are AI systems that learn an internal representation of an environment to predict how it changes over time. Traditional world models often require deep networks for faithful long-horizon simulation, which are expensive and prone to compounding errors. Looped architectures reuse the same parameters across multiple iterations, providing an inductive bias for compositional reasoning and enabling deeper effective computation without increasing parameter count.
