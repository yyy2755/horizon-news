## [AI4AI-Bench: New Benchmark for LLM Agents in Algorithmic Design](https://arxiv.org/abs/2608.20318) ⭐️ 9.0/10

AI4AI-Bench is a new benchmark introduced in an arXiv paper that evaluates LLM agents' ability to redesign training algorithms across 10 frozen research repositories. In each task, agents have 4 hours on one B300 GPU to rewrite the training algorithm, and their code is rerun for up to 12 hours and scored against the original algorithm. This benchmark is significant because it isolates the ability to design training algorithms, a key step toward recursive self-improvement (RSI) in AI. The results show that even the strongest systems close less than a fifth of the gap between existing algorithms and the optimum, highlighting the current limitations and providing a measurable target for future progress. The benchmark includes 10 tasks, each mapped onto a common scale where 0 is an uninformative model, 0.1 is the repository's original algorithm, and 1.0 is the task optimum. Across 29 configurations of 6 systems, the mean score is 0.166, with the best system reaching 0.250; submissions that actually change the learning algorithm average 0.226 versus 0.126 for those that do not.

rss · ArXiv ML (cs.AI) · Aug 21, 04:00

**Background**: Recursive self-improvement (RSI) is a hypothesized process where an AI system improves the process that produces AI systems, potentially leading to an intelligence explosion. The training algorithm is central to this process, as a better objective or update rule improves the compute-capability exchange rate for every subsequent run. Existing benchmarks for LLM agents focus on data collection or hyperparameter tuning, but none isolate the ability to design training algorithms, which AI4AI-Bench aims to address.

## [Researcher Accidentally Hijacks ENUM, Logs Military Calls](https://lina.sh/blog/hijacking-e164-arpa) ⭐️ 8.0/10

A security researcher accidentally hijacked e164.arpa ENUM queries, logging hundreds of thousands of phone calls to military bases. The incident highlights a critical but overlooked vulnerability in telephony infrastructure. This discovery reveals a significant security flaw in the global telephony routing system, potentially allowing unauthorized parties to intercept or redirect calls. It underscores the need for better oversight and security measures in ENUM infrastructure, affecting telecom providers and national security. The researcher did not set up a SIP server to test if calls could be terminated, but the scale of data collection was massive. The vulnerability stems from the fact that e164.arpa ENUM is largely non-public but still used for number portability via private nameservers.

hackernews · gavide · Aug 21, 13:11 · [Discussion](https://news.ycombinator.com/item?id=49387570)

**Background**: ENUM (Telephone Number Mapping) is an IETF protocol that maps E.164 telephone numbers to URIs using the e164.arpa domain, enabling services like VoIP routing. It was designed to be a public directory but never fully took off, and now it is mostly used in private contexts, such as number portability databases. The researcher's accidental hijack occurred because the e164.arpa zone was left unsecured, allowing unauthorized queries to be logged.

## [Active Inference Framework for Efficient Context Acquisition in AI Agents](https://arxiv.org/abs/2608.19202) ⭐️ 8.0/10

This paper introduces active inference as a principled framework for context acquisition in AI agents, formalizing the tradeoff between clarification costs and task performance. It instantiates the framework in Optimal Question Asking (OQA) benchmarks and tests frontier language models on tasks with 25 to 300 candidates. This work addresses a practical problem in interactive AI systems: efficiently acquiring the right context. By providing a model-agnostic design principle, it could improve the efficiency and effectiveness of AI agents in real-world applications, potentially reducing token costs and enhancing user experience. The framework uses an inner inference step to update beliefs over a latent task state and an outer decision to select the next action, minimizing expected free energy. In deterministic settings, the epistemic term reduces to expected information gain, optionally normalized by token cost. The paper also studies clarification before generation and automated prompt optimization under token budgets.

rss · ArXiv ML (cs.AI) · Aug 21, 04:00

**Background**: Active inference is a Bayesian framework originating from neuroscience that explains perception and action as minimizing free energy. It has been applied to AI agents to model agency and decision-making. The paper applies this framework to the context-acquisition layer of AI agents, where agents must decide whether to ask clarifying questions or proceed with default assumptions.

## [Bounded Sovereignty and Control Tax: Pricing AI Oversight Without Model Ownership](https://arxiv.org/abs/2608.19216) ⭐️ 8.0/10

This paper introduces the concept of bounded sovereignty, which describes partial technical and contractual access across the data, model, infrastructure, and interaction layers of the AI stack, and proposes a 'control tax' framework to price AI oversight when deployers do not own the model. It provides a four-layer access typology, a protocol-by-layer requirements matrix, and the concept of sovereignty discount cost. This work addresses a critical gap in AI control research by acknowledging that many control protocols assume deployer access to model internals, which often fails for regulated organizations using frontier models via APIs. It provides a practical framework for pricing oversight and highlights the need for explicit access assumptions in control protocols, impacting AI safety and governance. The paper reports a synthetic access-ablation experiment over 1.35 million simulations, showing that complete logs improve diagnosis, a pre-execution gateway enables intervention, trace access and model-version control strengthen post-incident explanation, and scope restriction can improve safety while reducing usefulness. The experiment is a construct-validity exercise, not real-world payment-system evidence.

rss · ArXiv ML (cs.AI) · Aug 21, 04:00

**Background**: AI control research aims to deploy models safely even when they may be misaligned, but many protocols assume deployers can instrument the model and its pipeline. However, regulated organizations using frontier models through APIs often lack access to model weights, serving infrastructure, internal traces, or full logs. The concept of 'control tax' was introduced in earlier work to capture the operational and financial cost of integrating control measures into AI pipelines. This paper extends that idea by considering partial access and introducing 'bounded sovereignty' to describe the access conditions that determine which control protocols are feasible.

However, in real-world scenarios, users often give repetitive instructions, and AgriVLN treats each instruction as an independent episode, missing the opportunity to leverage past spatial memories.
