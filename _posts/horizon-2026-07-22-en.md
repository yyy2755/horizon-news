## [Apollo 11 Guidance Computer Source Code on GitHub](https://github.com/chrislgarry/Apollo-11) ⭐️ 9.0/10

The original Apollo 11 guidance computer source code for both the command and lunar modules has been shared on GitHub, offering a rare glimpse into the software that guided humanity's first Moon landing. This code is a historically significant artifact that showcases pioneering software engineering under extreme resource constraints, inspiring modern developers and preserving computing history. The repository includes the Colossus 2A (command module) and Luminary 1A (lunar module) source code, written in AGC assembly language, with comments revealing clever optimizations like a 9th-degree polynomial for moon position.

**Background**: The Apollo Guidance Computer (AGC) was one of the first computers designed for small size and real-time control, with only 36K words of memory. The code was written in a custom assembly language and had to fit within severe constraints, yet it successfully guided astronauts to the Moon and back.

Researchers introduced SysAdmin, a benchmark that places frontier language models as autonomous system administrators in a Linux sandbox to measure power-seeking across five dimensions, finding corrected estimates of 0–5% across seven models. This benchmark directly addresses a critical AI safety risk—loss of control due to power-seeking—by providing a standardized method to detect such behaviors in frontier models, which is essential for alignment research. ## [Record Quantum Cryptanalysis on IBM Hardware Extends Period Recovery](https://arxiv.org/abs/2607.18340) ⭐️ 9.0/10

Researchers have demonstrated genuine, textbook-faithful quantum cryptanalysis on IBM's Heron-generation quantum processor (ibm_kingston), recovering the hidden period of the Even-Mansour cipher up to security parameter N=10, surpassing the previous record of N=4. They also recovered periods of a 3-round Feistel construction at block sizes 6 and 8, and verified a 21-qubit block-10 instance in simulation. This work demonstrates that quantum cryptanalysis on real hardware can scale beyond small toy examples, potentially impacting the security assessment of symmetric ciphers. It provides a benchmark for five genuine quantum attacks across four cipher paradigms, offering insights into the practical capabilities of near-term quantum devices. The attacks use Simon's algorithm, Bernstein-Vazirani, and Grover's algorithm, but are limited to reduced or structured constructions in the Q2 model and do not achieve quantum advantage over classical collision-finding. The experiments rely on error mitigation rather than fault-tolerant error correction, and all attacks are validated up to a classical simulation ceiling of 25 qubits.

rss · ArXiv ML (cs.AI) · Jul 22, 04:00

**Background**: The Even-Mansour cipher is a simple method to construct a keyed pseudorandom permutation from a public random permutation, widely used in symmetric-key constructions. Simon's algorithm is a quantum algorithm that can find hidden periods exponentially faster than classical algorithms, and it inspired Shor's algorithm. Feistel ciphers, such as DES, use a symmetric structure where the block is split into halves and processed through multiple rounds.

## [SkewAdam Cuts MoE Optimizer Memory by 97.4%](https://arxiv.org/abs/2607.19058) ⭐️ 9.0/10

Researchers propose SkewAdam, a tiered optimizer that allocates different state configurations to backbone, experts, and router in MoE training, reducing optimizer memory from 50.6 GB to 1.29 GB and peak memory from 81.4 GB to 31.3 GB, enabling training on 40 GB accelerators. This breakthrough addresses a critical memory bottleneck in large-scale MoE language model training, making it feasible to train models on widely available hardware without sacrificing accuracy, which could democratize access to MoE training. SkewAdam uses float32 momentum plus factored second moment for the backbone (5% of parameters), factored second moment only for experts (95%), and exact second moment for the router (<0.01%).
