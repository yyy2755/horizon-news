The project is available on GitHub and includes the original source code and resources. This port is a significant technical achievement for retrocomputing enthusiasts, as it preserves and makes accessible a seminal piece of software history on modern hardware. It also demonstrates the feasibility of porting 16-bit Windows applications to x64, which could inspire similar projects for other legacy software. The port replaces 16-bit assembly, segmented-memory, and Win16 platform boundaries with modern equivalents, while retaining the original C source and resources. The project is source-only, with no precompiled binary provided, and some users have reported build issues, such as a missing CMake file.

This port overcomes those limitations by recompiling the original source code for the x64 architecture.

## [Shopify Replaces Redis with MySQL for Scalable Inventory Reservations](https://shopify.engineering/scaling-inventory-reservations) ⭐️ 7.0/10

Shopify engineers replaced Redis with MySQL for inventory reservations, using a row-per-unit model with bounded pools capped at 1,000 rows per item/location combination. This approach achieved scalability and durability, as detailed in a recent engineering blog post. This change addresses the scalability and durability limitations of Redis for critical inventory operations, offering a simpler and more reliable alternative. It could influence how other companies design their inventory systems, especially those facing similar concurrency and atomicity challenges. The row-per-unit model stores one row per sellable unit instead of a quantity column, and a bounded pool of available rows (capped at 1,000 per item/location) prevents performance degradation. Reservations consume rows from the pool, and a replenishment process refills it, ensuring atomicity and durability.

hackernews · adletbalzhanov · Aug 8, 22:32 · [Discussion](https://news.ycombinator.com/item?id=49226536)

**Background**: Inventory reservation systems must handle concurrent decrements of a single number without overselling. Redis is fast and single-threaded, but it lacks durability and can become a bottleneck at scale. MySQL provides ACID transactions and durability, making it a viable alternative when designed with techniques like row-per-unit and bounded pools.

Tom Stanton, a DIY engineer, has built a trebuchet that launches a 4-gram projectile at 776 miles per hour, breaking the sound barrier using only gravitational potential energy. The achievement was showcased in a YouTube video that has garnered over 1.5 million views. This feat demonstrates that ancient mechanical principles can be pushed to modern extremes, potentially inspiring new applications in low-resource projectile systems or educational demonstrations. It also sparks interest in the physics of high-speed mechanical launches, which could have niche defense or industrial uses. The projectile weighed only 4 grams (about 62 grains), which is roughly twice as heavy as a 30-grain .22LR round and 1.5 times as heavy as a 40-grain subsonic round. The trebuchet uses a counterweight and sling mechanism, and the design was optimized through software modeling to achieve supersonic speeds.

Historically used as a siege engine, it was a common weapon until the advent of gunpowder. Breaking the sound barrier with a trebuchet is a significant engineering challenge because it requires extremely efficient energy transfer and minimal aerodynamic drag.
